# Maps

`NgaTuSo.xodr`: Ngã Tư Sở, Hà Nội (~900 m × 900 m, bbox 20.9988,105.8155 – 21.0070,105.8245), built with
`osm_map.py` from OpenStreetMap road data (Overpass API). Bridges / elevated ways (Ngã Tư Sở flyover,
elevated ring road 2) are dropped: CARLA 0.9.10 cannot build overlapping roads.
